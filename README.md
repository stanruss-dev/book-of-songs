# Книга песен для iPhone

Устанавливаемое веб-приложение (PWA), не требующее Mac, Xcode или Apple Developer Program.

## Публикация

Содержимое каталога публикуется в корень отдельной ветки `gh-pages`. После включения
GitHub Pages приложение доступно по адресу:

`https://stanruss-dev.github.io/book-of-songs/`

На iPhone открыть адрес в Safari, нажать «Поделиться» → «На экран Домой» → «Добавить».

## Данные

- полный снимок песен и очередь дат хранятся в IndexedDB на устройстве;
- без интернета добавленные и изменённые даты остаются в очереди;
- при запуске, восстановлении сети и по кнопке выполняется синхронизация с GitLab;
- приложение меняет только даты исполнения, песни и тексты редактируются на компьютере;
- строки подсвечиваются по давности последнего исполнения так же, как в настольной версии;
- список сортируется по номеру, названию, исполнению, тематике или дате изменения;
- GitLab-токен сохраняется только в хранилище сайта на конкретном iPhone.
